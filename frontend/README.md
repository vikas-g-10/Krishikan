# Farm AI Hub

Build the initial frontend shell for a project called KRISHI-NEXUS.

KRISHI-NEXUS is an AI-powered agricultural decision-support system for farmers. It is NOT a generic chatbot. The UI should feel like a modern agricultural AI control room.

For this first step, ONLY build the frontend structure and visual design. Do NOT modify, create, or assume any backend/API/AI architecture.

Create a responsive dashboard with:

1. A left sidebar:

   - KRISHI-NEXUS logo/name

   - Dashboard

   - My Farm

   - AI Decisions

   - Decision History

   - Settings

2. A main dashboard area:

   - Header with farmer greeting

   - Farm/location summary

   - Current crop and growth stage

   - Weather summary card

   - Soil/field status card

   - Recent AI decision card

3. A prominent "Ask KRISHI-NEXUS" section:

   - Text input

   - Photo upload button

   - Voice input button

   - Kannada / English language toggle

4. Create a clean agricultural visual style:

   - professional, trustworthy, modern

   - green/natural visual language

   - rounded cards

   - clear status indicators

   - mobile responsive

   - avoid making it look like a generic AI chat application

Use realistic demo/mock data only for visual rendering. Clearly keep mock data separate from any future backend integration.

IMPORTANT:

- Do NOT implement AI logic.

- Do NOT create API calls.

- Do NOT create database logic.

- Do NOT change or assume anything about the existing KRISHI-NEXUS backend.

- Do NOT implement authentication yet.

- Keep the code modular so we can connect the existing backend later.

After completing this step, report:

1. Files created/modified

2. Frontend routes created

3. Any dependencies added

4. Confirmation that no backend/API logic was changed.
